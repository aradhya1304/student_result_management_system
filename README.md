<h1>⚙️ Installation</h1>

<h2>1️⃣ Clone Repository</h2>

<pre>
git clone https://github.com/YOUR_USERNAME/student_result_management_system.git
cd student_result_management_system
</pre>


<h2>🐬 MySQL Setup</h2>

<p>Open MySQL Workbench:</p>

<pre>
CREATE DATABASE student_result_db;

USE student_result_db;
</pre>

<p>Then execute:</p>

<pre>
sql/database.sql
</pre>


<h2>🔐 Database Configuration</h2>

<p>Configure the connection in:</p>

<pre>
src/Database.cpp
</pre>

<p>Example:</p>

<pre>
host = "localhost";
username = "root";
password = "YOUR_PASSWORD";
databaseName = "student_result_db";
</pre>

<table width="100%">
<tr>
<td>

⚠️ <strong>Never commit your real MySQL password to GitHub.</strong>

</td>
</tr>
</table>


<!-- ========================================================= -->
<!--                         COMPILE                           -->
<!-- ========================================================= -->

<h2>🔨 Compile</h2>

<pre>
g++ -std=c++17 src/*.cpp -Iinclude -o student_result
</pre>


<h2>▶️ Run</h2>

<h3>Windows</h3>

<pre>
student_result.exe
</pre>

<h3>Linux / macOS</h3>

<pre>
./student_result
</pre>
